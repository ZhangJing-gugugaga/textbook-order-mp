# 教材征订小程序 · MVP 演示版

微信小程序原生开发，全部数据为本地 mock（无需服务器），用于向老师演示完整征订流程与数据统计能力。

## 功能清单

| 模块 | 说明 |
|------|------|
| 登录 | 学号/工号 + 姓名严格匹配在册名单，匹配不上无法进入；自动识别学生 / 教材管理员角色 |
| 学生端 | 按学号自动带出本班关联教材 → 勾选 + 数量 → 提交，截止前可修改 |
| 管理员端 | 发布征订任务（选班级 + 勾教材 + 设截止）、教材管理（手动添加 / Excel 粘贴批量导入）、任务状态控制 |
| 统计导出 | 班级 / 专业 / 学院订书比例（条形图 + 饼图）、教材征订数量与金额汇总、漏订催办名单、一键导出 CSV |
| 消息 | 站内信占位（微信订阅消息推送能力待定） |
| 支付 | 按老师需求，本期无支付环节 |

## 如何运行

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）
2. 打开工具 → 导入项目 → 选择本目录（`textbook-order-mp`）
3. AppID 选择「测试号」（project.config.json 已预置 `touristappid`，游客模式可直接跑）
4. 编译即可在模拟器体验；点「预览」生成二维码，自己微信扫码可真机体验

## 如何给老师演示

**方式 A · 当面演示（推荐，零配置）**
同一台手机上切换账号即可演示完整闭环：
1. 用学生账号登录 → 勾选教材 → 提交
2. 退出 → 用管理员账号登录 → 查看统计（比例实时变化）→ 导出表格
> Mock 数据存在本机 storage，同一台设备上所有角色共享数据，切换账号能看到对方提交的结果。

**方式 B · 远程扫码体验（需要 AppID）**
1. 注册小程序账号：[mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 小程序（个人主体免费），拿到 AppID 填入 `project.config.json`
2. 开发者工具右上角「上传」→ 微信公众平台「版本管理」→ 将上传版本设为「体验版」
3. 「成员管理」→ 添加老师的微信号 为体验成员
4. 生成体验版二维码发给老师，微信扫码即可使用
> 注意：每台手机的 mock 数据相互独立，老师手机里是全新的种子数据，需自行走一遍「管理员发布 → 学生提交 → 管理员看统计」流程。

## 已知边界（MVP）

- 数据为本地 mock，刷新/删除小程序即重置为种子数据
- Excel 导入采用「复制粘贴解析」方案（真机端解析 xlsx 文件需要后端或云函数，见下）
- 消息推送为站内占位，订阅消息待老师确认后接入
- CSV 导出 = 生成文本复制剪贴板，电脑 Excel 打开后直接粘贴

## 后续升级路径（接真实后端）

- 数据层集中在 `utils/store.js`，接口签名已抽象好，接后端时只需替换该文件实现（或改造成 wx.request 调 API），页面零改动
- Excel 真文件解析：`wx.chooseMessageFile` 选文件 + 云函数解析（`xlsx` 库）→ 批量入库
- 通知推送：微信订阅消息（`wx.requestSubscribeMessage`），四类节点定时触发
- 登录对接：学校统一身份认证或学信网校验（需学校接口配合）

## 技术栈

微信小程序原生（WXML/WXSS/JS），无第三方依赖、无 npm 构建，Canvas 2D 手绘饼图。
