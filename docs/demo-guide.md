# 老师体验操作指引

本文档说明如何让老师体验教材征订小程序。共有两种方式，推荐**方式一（体验版二维码）**，老师在自己手机上随时可用；当面汇报可配合**方式二**。

---

## 方式一：体验版二维码（推荐，老师远程扫码即用）

> 前提：您已注册小程序账号（AppID `wx3e356ed2d2cc4a07` 对应的账号），并能扫码登录 mp.weixin.qq.com。体验版**无需审核**，添加老师为体验成员后即可长期使用。

### 第 1 步：上传代码 ✅ 已完成

代码版本 `1.0.0`（小程序端升级版）需在联调通过后重新上传：开发者工具右上角「上传」→ 填版本号与备注。

### 第 2 步：设置为体验版

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com)，用**管理员微信**扫码登录；
2. 左侧菜单进入「**版本管理**」；
3. 在「**开发版本**」列表中找到版本号 `1.0.0` 的条目，点击右侧「**选为体验版**」→ 确认；
4. 页面会出现「体验版」二维码——先别急着发给老师，还需完成第 3 步。

### 第 3 步：添加老师为体验成员（关键，漏了老师扫不出）

1. 左侧菜单进入「**成员管理**」→「**体验成员**」；
2. 点击「添加成员」，输入老师的**微信号**（老师微信「我 → 个人信息 → 微信号」里查看）；
3. 确认添加。小程序体验成员数量上限充足（个人主体 15 人），随时可增删。

### 第 4 步：把二维码发给老师

1. 回到「版本管理」→「体验版」区域，点击二维码可放大/下载；
2. 将二维码图片发给老师，老师用**微信扫码**即可进入小程序；
3. 老师首次进入可能提示「申请获取你的昵称等」，点允许即可。

### 注意事项

- **数据来自服务端**：小程序为纯客户端，师生看到的是同一份后端数据（与 Web 端一致），不再是各设备独立的本地演示数据；
- 演示前请确认后端已部署且  的  指向可用环境；
- 代码每次更新后需要**重新上传并重新「选为体验版」**，二维码不变。

## 方式二：当面演示（汇报场景，零配置）

### A. 电脑模拟器（最稳）

1. 微信开发者工具打开本项目，编译已通过，模拟器直接可操作；
2. 建议投屏或让老师坐旁边看。

### B. 真机演示

1. 工具栏点「预览」→ 生成二维码 → **您自己**的微信扫码（仅开发者及体验成员可扫）；
2. 手机上即可操作真实界面。

### 演示脚本（完整业务闭环，约 4 分钟）

| 步骤 | 操作 | 演示点 |
|------|------|--------|
| 1 | 登录页点「任课老师」演示卡（700101 / Tea@12345）→ 登录 | 工号 + 密码登录，按权限码落地教师首页 |
| 2 | 首页 →「任课关系」→ 点课程进填报页 | 课程 × 班级定位到对应明细行 |
| 3 | 点「＋ 新增明细行」→ 选教材（关键词检索）→ 填数量 | 明细行编辑器（非勾选清单） |
| 4 | 把数量改成 9999 →「提交填报」→ 确认 | **字段审查回显**：顶部汇总 + 行级红字「第 N 行：数量需在 1-50 之间」 |
| 5 | 删掉问题行 → 重新提交 | 补正重提 → 状态转「待审核」 |
| 6 | 点「我的提交记录」 | 审查状态轨迹：提交 → 系统字段审查 → 内容审核 → 结果 |
| 7 | 「我的」页看身份卡 / 通知确认 / 退出登录 | 通知阻塞弹窗与确认闭环 |
| 8 | 换学生卡（20230101 / Stu@12345）登录 →「去勾选教材」 | 本班教材清单、必修默认勾选、数量步进、合计金额 |
| 9 | 提交 → 明细确认弹层（含「价格和版本以最终出版单位供应为准」）→ 确认 | 覆盖语义提交 |
| 10 | （可选）用 700103 登录体验「切换身份」 | 秘书身份 → Web 端引导 → 切回任课老师 |

> 教师端不提供导出，统计与导出在电脑端 Web 系统演示；如需展示「提交后学生清单变化」，请用管理员账号在 Web 端审核通过该填报。

## 方式三：正式发布（本次演示不需要）

正式上线需要提交微信审核，教育类目可能要求办学资质材料，且流程较长。演示、试用场景一律使用体验版即可。

---

## 给老师的体验引导话术（可直接复制）

> 老师您好，扫码进入后可以看到教材征订的完整流程：
> 先点「任课老师」演示卡，进「我的课程」点一门课，就能按 课程 × 班级 逐行填写教材和数量；
> 故意把数量填大一点提交，系统会直接把问题定位到具体行，改完再提交即可；
> 再切到「学生」卡，能看到学生端按班级带出的教材清单、勾选与提交确认；
> 数据都来自学校教材征订服务，和电脑端是同一份，随便操作不会影响真实数据。
