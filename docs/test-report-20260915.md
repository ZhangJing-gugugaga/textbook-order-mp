## 三、问题清单与修改建议

### P1 · 功能缺陷（建议优先修复）

**问题 1：统计页学院/专业名称全部不显示（#35，连带 #39）**
- 现象：「学院订书比例」图例只有色点+百分比没有学院名；学院/专业条形图名称空白；CSV 汇总表学院/专业名称为空。
- 根因：`utils/store.js:339` —— `aggregate()` 中 `name: info[levelKey + 'Name']`。当 `levelKey='collegeId'` 时取的是 `info['collegeIdName']`（不存在，undefined），实际字段名是 `collegeName`；`majorId` → `majorName` 同理。
- 修复建议：
  ```js
  // store.js getStats() aggregate 内，原 339 行
  if (!map[key]) map[key] = { id: key, name: info[levelKey === 'collegeId' ? 'collegeName' : 'majorName'], total: 0, submitted: 0 };
  ```
  或通用写法 `info[levelKey.replace('Id', '') + 'Name']`。

**问题 2：统计页班级维度名称只有「1班/2班」（#35）**
- 现象：班级比例只显示「1班」「2班」，多专业下无法区分是哪个班的 1 班。
- 根因：`utils/store.js:326` —— `name: cls ? cls.name : cid`，种子里班级 `name` 字段仅是班号（'1班'），未拼专业与年级。
- 修复建议：改用组合班级名：
  ```js
  // store.js getStats() byClass 内，原 326 行
  const full = getClassFull(cid);
  name: full ? full.className : cid,   // "计算机科学与技术级2024级1班"
  ```

**问题 3：导入学生遇旧格式班级数据会静默重复建班（#32，数据兼容性）**
- 现象：实测中 storage 存在旧版班级记录（无 `grade` 字段、班级名含「2024级」，如 `{id:'CST2401', majorId:'CST', name:'2024级1班'}`）时，导入「2024级1班」解析为 `grade='2024', name='1班'`，与旧记录匹配失败 → 新建重复班级 K*，学生被挂到新班。清空重播种后复测**匹配正常**（学生正确挂 CST2401，无新建），确认当前代码逻辑无误，属旧数据格式不兼容。
- 影响：一旦用户设备存有旧版本数据（升级安装/历史缓存），导入学生将产生重复班级且无任何提示。
- 修复建议（任选或组合）：
  1. `findOrCreateClass()` 增加兜底：按 `getClassFull` 组合出的 className 全称匹配一次；
  2. `store.init()` 播种前对已有班级数据做一次格式迁移（补 `grade` 字段、拆分 name）；
  3. 导入建链产生新班级时在结果提示中列出新建班级，便于管理员发现异常。

### P2 · 体验瑕疵（建议优化）

**问题 4：已截止任务详情页仍显示可点击的「提交征订」按钮（#15）**
- 现象：截止任务进入详情后，教材仍可勾选/改数量，底部「提交征订」按钮可点，点了才 toast「该任务已截止」。逻辑拦截有效，但体验是「白忙一场」。
- 建议：`pages/order/order.wxml` 对 `order.status !== 'open'` 时：禁用勾选与步进器（`pointer-events: none` 或条件渲染只读态），底部按钮换成禁用态「已截止 · 仅供查看」。

**问题 5：班级名重复拼接「计算机科学与技术计算机科学与技术2024级1班」（#38、#39）**
- 根因：`pages/admin-stats/admin-stats.js:67` 的 `info.majorName + info.className` 与 `utils/export.js:32` 的 `cls.collegeName + cls.majorName + cls.className`——`className` 本身已含专业名，再拼 majorName 造成重复。
- 建议：催办名单直接用 `info.className`；CSV 明细用 `cls.collegeName + ' / ' + cls.className`（或加空格分隔），避免语汇粘连。

**问题 6：任务名状态后缀重复「2025年春季学期补订（已截止）（已截止）」（#40）**
- 根因：`pages/admin-stats/admin-stats.js:31` 无条件给标题追加状态后缀，而任务标题本身已含「（已截止）」。
- 建议：拼接前检测标题是否已含状态字样；或演示任务命名去掉状态字样，状态统一由后缀表达。

**问题 7：「我的」页右上角角色标签文字竖排换行（#17）**
- 现象：「学生」两字因标签容器过窄被挤成上下两行（见截图 test_17_profile.png 右上角）。
- 建议：该标签样式加 `white-space: nowrap; min-width` 适配；「教材管理员」四字场景需一并验证。
