### 2.3 修复的缺陷（7 项）

| # | 缺陷 | 严重度 | 根因与修复 |
|---|---|---|---|
| 1 | **页面运行时报错**：`module '@babel/runtime/helpers/arrayWithHoles.js' is not defined` | 高（页面不可用） | 原生小程序无 npm 构建，**数组解构**（`]).then(([a,b]) => …)`）会引入 babel runtime helper。3 处改为下标取值，并复查全仓无残留 |
| 2 | **登录后被弹回登录页** | 高（主链路） | `app.whenSessionReady()` 缓存了启动时的 `{ok:false}`，登录成功后首页/我的页仍拿到旧结论。修复：登录落地时 `app.setSession(me)` 刷新缓存 + `whenSessionReady` 自愈（本地有令牌时重新判定）。同时修复 MVP P3 #8（有会话仍显示登录页） |
| 3 | **字段审查错误被刷新冲掉** | 中 | `FIELD_CHECK_FAILED` 后立即 `loadAll()` 会重建明细行并清空行级错误，用户看不到「第 N 行」提示。改为保留用户编辑行 + 行级错误，仅刷新状态与补正截止；并在进入页面时用表单自带 `fieldCheckResult` 回显问题行 |
| 4 | **超管/秘书被放进教师首页** | 中（越权面） | `homeMode()` 只按权限码判定，而 ADMIN 权限是超集（35 条，含两个 submit 码）。改为按身份码排除 ADMIN/SECRETARY/SUPPLIER，师生之间仍按权限码区分 |
| 5 | **退出登录后被弹回业务页** | 中 | `clearSession()` 未作废 `app.globalData.sessionPromise`（仍是退出前的 `{ok:true}`），登录页 onLoad 据此立即 `land()`。已在 clearSession 内同步置为 `{ok:false}` |
| 6 | **「我的」页通知区首屏不加载** | 低 | `onShow` 早于会话就绪，`if (!this.data.me) return` 直接跳过。改为 onLoad 会话就绪后补一次加载 |
| 7 | **填报页合计金额恒为 ¥0.00** | 低（误导） | 预填行教材单价需额外检索才能取全，金额会失真。教师填报按「行数 / 册数」计量（§5.4.2），移除金额展示 |
